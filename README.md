# Theatrix: Theater Practice Assistant

A web-based tool that helps actors rehearse lines using real-time speech recognition. The app listens as you perform a scene and automatically follows along with the script, updating progress as you speak.

---

## Features

* Real-time speech recognition using the Web Speech API
* Multiple scene selection (Hamlet, Romeo & Juliet, Macbeth)
* Live transcription with word-level matching
* Automatic line progression during natural speech
* Works on desktop and mobile (Chrome recommended)

---

## How it works

The app listens to the user’s voice and converts speech into text. It compares the spoken text with the current script line and updates the display in real time. As the user continues speaking, the app automatically progresses through the scene.

---

## Tech Stack

* HTML
* CSS
* JavaScript
* Web Speech API (SpeechRecognition)

---

## Notes

* Microphone permission is required
* Best supported in Google Chrome (desktop or Android)
* iOS Safari support is limited

---

## Setup

Open `index.html` in a browser or deploy using GitHub Pages.

---

## Inspiration

Built to make script rehearsal more natural and interactive by removing the need for manual navigation or clicking through lines.
